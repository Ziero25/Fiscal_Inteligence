# 📊 Fiscal Intelligence Portal

> Uma plataforma avançada para agregação, análise e visualização de dados fiscais técnicos (NF-e, Sefaz) e discussões da comunidade.

---

## 🌟 Destaques do Projeto

O **Fiscal Intelligence Portal** foi desenvolvido para transformar dados brutos do governo em insights acionáveis. Com uma interface premium e um pipeline de extração de dados paralelo, o portal oferece uma experiência fluida para profissionais da área fiscal.

- **Interface Glassmorphic:** Design moderno, limpo e responsivo.
- **Painel de Controle (Dashboard):** Visualização clara de métricas e tendências.
- **Pipeline de Scraping Robusto:** Extração enriquecida de conteúdos do Sefaz e tópicos técnicos.
- **Navegação Inteligente:** Filtragem por categorias e deep-linking para acesso rápido.

---

## 🛠️ Tecnologias Utilizadas

### Frontend
- **HTML5 & CSS3:** Estrutura semântica e estilização customizada (Vanilla CSS).
- **JavaScript (ES6+):** Lógica dinâmica, transições de página e manipulação de DOM.
- **Google Fonts (Inter, Outfit):** Tipografia moderna e legível.

### Backend & Automação
- **Python 3.12:** Coração do sistema de coleta de dados.
- **Parallel Processing:** Scripts otimizados para extração simultânea de dados.
- **Data Enrichment:** Limpeza e enriquecimento de conteúdos para relatórios técnicos.

---

## 🚀 Como Executar

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Ziero25/Fiscal_Inteligence.git
   ```

2. **Interface Web:**
   Abra o arquivo `app/index.html` em seu navegador ou utilize um servidor local (como Live Server).

3. **Scripts de Coleta (Python):**
   - Certifique-se de ter o Python instalado.
   - Configure o arquivo `.env` com as chaves necessárias.
   - Execute o script principal:
     ```bash
     python execution/fetch_all.py
     ```
